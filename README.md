# 美菜 B2B2C 闭环系统 Demo

一套餐饮行业 B2B2C 闭环演示项目，覆盖：

- 消费者点餐小程序（微信小程序 / Taro）
- 餐厅 POS 收银系统（Web 端）
- 餐厅后厨 KDS（厨显系统）
- 美菜平台采购对接（供应商/管理后台）

## 闭环业务

```
消费者扫码点餐 ──→ 餐厅 POS 接单收银 ──→ 后厨 KDS 出餐
                                          │
                                          ↓
                                  餐厅库存消耗 / BOM
                                          │
                                          ↓
                              库存预警 → 平台采购食材 ──→ 供应商报价
```

## 目录结构

| 目录 | 说明 | 技术栈 |
| --- | --- | --- |
| `miniapp/` | 消费者点餐小程序 | Taro + React + TypeScript + Zustand |
| `pos/` | 餐厅 POS 收银 + KDS 后厨 | HTML + CSS + 原生 JS |
| `admin/` | 美菜平台管理后台 | HTML + CSS + 原生 JS |
| `supplier/` | 供应商端 | HTML + CSS + 原生 JS |
| `user/` | 老版用户端 H5 | HTML + CSS + 原生 JS |
| `assets/` | 公共样式 | CSS |

## 核心功能

### 小程序（miniapp）
- 扫码绑定桌号（小程序码 scene 解析）
- 微信授权登录 + 手机号绑定
- 微信支付 / 会员卡储值支付
- 订单状态实时回传（KDS 出餐同步）
- 订单详情进度时间线

### POS 收银（pos）
- 桌台管理（空闲/就餐/预订）
- 收银结算（多种支付、找零、打印小票）
- 菜品与配方 BOM 管理
- 库存管理 + 损耗登记 + 盘点调整
- 后厨 KDS（接单→制作→出餐叫号）
- 退款处理 / 日结 / 会员营销
- 采购下单（对接美菜平台）

### 平台后台（admin）
- 商品/分类/订单/用户/会员/权限/员工/供应商/库存/纠纷/询价/评价/退款/操作日志

### 供应商端（supplier）
- 入驻申请 / 商品发布 / 报价管理 / 订单处理
